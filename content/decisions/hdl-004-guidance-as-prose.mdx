## Context

Which chart answers which kind of data question was knowledge held individually, taught person to person. A catalogue of available chart types would not transfer it — the useful part is the judgement, not the inventory.

## Decision

Write the guidance as prose. Each entry names the visualisation type, explains what it is for, and shows a worked example, across the full set of question types the team encountered.

## Alternatives considered

**A component index with usage labels.** Not adopted. It tells a designer what exists, not what to choose or why.

## Consequences

The guide answers the harder question and is the section that removed the need to teach new joiners individually. It is also the part that ages fastest: prose has to be revised as the platform's rendering capability changes, where an index would only need entries added.
